# Showy — плагин для Lampa без подписки

Патченная сборка плагина Showy. Работает без PRO-подписки: авторизация подставляется
автоматически, модалки оплаты не блокируют просмотр.

## Установка

В Lampa → Настройки → Расширения → «Добавить плагин по URL»:

```
https://cdn.jsdelivr.net/gh/Mffff4/showy-fixed@v22/showy-fixed.js
```

Перезапустить Lampa.

## Что изменено

- Пул токенов авторизации вшит в плагин и подставляется по умолчанию —
  подписка и ввод кода не требуются
- Токен добавляется в каждый запрос к источнику (`requestParams`)
- При отказе сервера (`Не авторизован`, `Продлите PRO-подписку`, истёк,
  неактивна) токен ротируется на следующий из пула и запрос повторяется
  (до 3 попыток), вместо модалки оплаты
- `showyVerifyProAuth`: статусы 400/401/403/404/409/422 больше не считаются
  фатальными — управление всё равно уходит в `onValid`

## Автономность

Плагин поддерживает себя сам:

- добыча токенов идёт фоном постоянно (по 32 запроса), позиция хранится в
  `showy_forage_pos` и переживает перезапуск — диапазон доходит за несколько
  часов обычного использования
- найденные живые токены проверяются через `check_pro_auth` и складываются в
  `showy_pool_extra`, подмешиваясь к вшитому пулу
- на отказ токен меняется на следующий, запрос повторяется

Ручных действий не требуется. Если всё-таки нужно ускорить — в репозитории
`brute_codes.py` гоняет то же самое с машины на 220 rps.

## Если все токены в пуле истекли

Коды активации шестизначные и проверяются без ограничения частоты — рабочий токен
можно добыть перебором за ~1 час:

```
python brute_codes.py      # диапазон 100000-999999, только активные токены
```

Скрипт пишет найденные активные токены в `found.json`. Их нужно вписать в
`SHOWY_TOKEN_POOL` в `showy-fixed.js` и выложить заново.

## Файлы

- `showy-fixed.js` — готовый плагин (аналог `online.js` с правками)
- `showy-fixed.loader.js` — короткий загрузчик, тянет плагин с того же хоста,
  что и сам (аналог `m.js`)
